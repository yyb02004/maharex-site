# Invitation fonts

Gowun Batang Regular is from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/gowunbatang), licensed under the SIL Open Font License in `OFL-GowunBatang.txt`.

`GowunBatang-Regular.woff2` is a subset for the invitation's fixed copy, with ASCII included. Regenerate after changing the Korean copy with `python scripts/build-love-font.py /path/to/GowunBatang-Regular.ttf` (requires `fonttools` and `brotli`). It is used for editorial headings, names and invitation prose; visitor-written content and form controls keep the system sans-serif font.

The existing Cormorant Garamond files use the license in `OFL-CormorantGaramond.txt`.
