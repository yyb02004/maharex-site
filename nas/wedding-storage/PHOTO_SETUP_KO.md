# 원본 사진 보관 · 관리자 사진 관리 업데이트

이번 업데이트부터 하객이 올린 JPEG·PNG·WebP 원본 파일을 변환 없이 NAS에 보관합니다. 하객에게는 촬영 위치 등 부가정보를 제거한 미리보기만 공개하고, 원본은 사진 관리 키를 가진 관리자만 내려받습니다. 기존에 올린 사진은 원본이 남아 있지 않아 **기존 축소본**으로 표시됩니다. 원본이 필요하면 업데이트 후 다시 올려 주세요.

## 1. 파일 복사

1. 전달받은 `wedding-storage-qnap-photos-20261026.zip`의 압축을 PC에서 풉니다.
2. `사진관리-접속키.txt`와 `참석명단-접속키.txt`는 PC에 따로 보관합니다. 키가 들어 있는 YAML과 ZIP도 하객에게 공유하지 않습니다.
3. 나머지 서버 파일과 `proxy` 폴더를 NAS의 **main → wedding**에 복사하고 같은 이름은 덮어씁니다.
4. `app.py`, `schema.sql`, `Dockerfile`, `photo-admin.html`, `rsvp-admin.html`이 wedding 폴더 바로 안에 있는지 확인합니다.

데이터는 기존 `maharex-wedding-data` 볼륨에 있습니다. 소스 파일을 덮어써도 사진·방명록·참석 명단은 보존됩니다. 업데이트 전에는 NAS의 기존 데이터 볼륨 백업을 권장합니다. 앱이나 볼륨을 삭제하지 않습니다.

## 2. 기존 앱 업데이트

1. **Container Station → Applications → composeqnap**을 엽니다.
2. **Edit 옆 화살표 → Recreate**를 선택합니다.
3. PC에서 압축을 푼 **compose.qnap.photos.yaml**을 메모장으로 엽니다.
4. 내용 전체를 복사해 Recreate 화면의 YAML을 전부 교체합니다.
5. **Advanced Settings → Resources → Memory limit → Limited / 1024 MB**로 설정합니다.
6. **Validate → Update**를 누릅니다. 새 이미지가 만들어지는 동안 잠시 기다립니다.

새 앱을 만드는 대신 기존 composeqnap을 업데이트합니다. 원본 저장 서버와 HTTPS 서버의 새 이미지 이름이 들어 있으며, 데이터·인증서 볼륨 이름과 참석 명단 키는 기존 값을 유지합니다. 기존 버전으로 되돌리면 원본 관련 DB 구조를 읽지 못하므로 업데이트 후에는 이전 이미지를 선택하지 않습니다.

## 3. 적용 확인

두 컨테이너가 **Running**이 되면 [연결 상태](https://wedding-api.maharex.com/api/health)를 엽니다.

`"ok": true`, `"originalPhotos": true`, `"photoAdmin": true`, `"rsvp": true`가 모두 보이면 새 기능이 준비된 것입니다. 청첩장을 새로고침하면 업로드 안내에 **원본 보관 동의**가 표시됩니다.

## 4. 사진 보기 · 삭제 · 내려받기

1. [사진 관리 화면](https://wedding-api.maharex.com/api/photo-admin)을 엽니다.
2. `사진관리-접속키.txt`의 키를 입력해 로그인합니다. 참석 명단 키와는 다른 키입니다.
3. 사진별 다운로드 버튼으로 원본을 저장할 수 있습니다. **기존 축소본**으로 표시된 사진은 남아 있는 JPG를 받습니다.
4. **삭제**를 누르고 해당 사진이 맞는지 확인한 뒤 삭제합니다. 공개 목록과 NAS의 원본·미리보기가 함께 삭제되며 되돌릴 수 없습니다.
5. **전체 다운로드**를 누르면 전체 사진이 ZIP으로 내려옵니다. 새 사진은 원본, 기존 사진은 축소본으로 구분되며 사진 목록도 포함됩니다.

전체 다운로드는 사진 수와 회사 인터넷 업로드 속도에 따라 시간이 걸립니다. 브라우저의 다운로드 목록에서 완료를 확인해 주세요. 다운로드 중에는 다른 사진을 삭제하지 않는 것이 좋습니다. 원본 파일에는 촬영 정보가 남아 있으므로 ZIP은 두 사람이 따로 보관해 주세요.

접속은 한 시간 동안 유효합니다. 공용 PC에서는 사용 후 **로그아웃**하세요. 키를 주소에 붙이거나 청첩장에 넣지 않습니다.

## 저장 공간과 백업

- 기존 볼륨: `maharex-wedding-data`
- 원본 파일: `/data/originals` (공개 URL 없음)
- 공개 미리보기·썸네일: `/data/media`
- 사진 정보·방명록·참석 명단: `/data/wedding.sqlite3`
- 원본을 포함한 사진 총 저장 한도: 10 GiB, 최대 5,000장
- 한 장: 15 MiB 이하, 4천만 화소 이하. JPEG·PNG·정지 WebP 지원

휴대폰이나 카카오톡이 파일 선택 전에 사진을 변환한 경우에는 **브라우저가 실제로 전송한 파일**이 원본으로 보관됩니다. HEIC는 현재 지원하지 않습니다.

ZIP은 사진 보관용이며 방명록·참석 명단까지 복구하는 NAS 전체 백업은 아닙니다. 서비스 전체를 백업하려면 앱을 잠시 중지한 상태에서 데이터 볼륨 전체와 인증서 볼륨을 별도로 백업합니다. NAS에서 이미지 파일만 직접 지우지 말고 사진 관리 화면을 사용해 주세요.
