# 참석 여부 전달 기능 연결하기

청첩장의 참석 여부 화면은 NAS에서 응답을 받을 준비가 끝나면 나타납니다. 아래 작업은 현재 실행 중인 **composeqnap** 앱을 업데이트하는 과정입니다.

## 1. 준비한 파일을 NAS에 복사하기

1. 전달받은 ZIP 파일의 압축을 PC에서 풉니다.
2. NAS의 **main → wedding** 폴더를 엽니다. 실제 경로는 `/share/main/wedding`입니다.
3. 압축 안의 서버 파일을 이 폴더에 복사하고, 같은 이름의 파일은 덮어씁니다.
4. `Dockerfile`, `app.py`, `schema.sql`, `rsvp-admin.html`이 **wedding 폴더 바로 안**에 있는지 확인합니다. wedding 안에 wedding 폴더가 한 번 더 생기지 않도록 해 주세요.

`참석명단-접속키.txt`는 PC에 따로 보관해 주세요. 참석 명단을 열 때 사용하는 키이며, 하객에게 공유하는 파일이 아닙니다.

## 2. 실행 중인 앱 업데이트하기

1. **Container Station → Applications → composeqnap**을 엽니다.
2. 오른쪽 위 **Edit** 옆의 화살표에서 **Recreate**를 선택합니다.
3. PC에서 준비된 **compose.qnap.rsvp.yaml** 파일을 메모장으로 엽니다.
4. 파일 내용 전체를 복사해, Recreate 화면의 YAML 내용을 전부 교체합니다. 파일에 들어 있는 접속키와 저장 공간 이름은 그대로 사용합니다.
5. **Advanced Settings → Resources → Memory limit**을 **Limited / 1024 MB**로 설정합니다.
6. **Validate**로 확인한 뒤 **Update**를 누릅니다.

기존 **composeqnap 앱을 업데이트**해 주세요. 새 앱을 만들거나 기존 볼륨을 삭제할 필요는 없습니다. 준비된 설정은 방명록·게스트 사진 저장 공간과 HTTPS 인증서 저장 공간을 이어서 사용합니다.

## 3. 연결 완료 확인하기

업데이트 중에는 잠시 연결이 끊길 수 있습니다. 작업이 끝나면 Containers에서 청첩장 저장 서버와 HTTPS 서버, **두 항목 모두 Running**인지 확인합니다.

다음 주소를 엽니다.

[참석 여부 연결 상태 확인](https://wedding-api.maharex.com/api/health)

화면에 **`"ok": true`**와 **`"rsvp": true`**가 나오면 참석 정보를 받을 준비가 된 것입니다. 아직 `rsvp` 항목이 없거나 `false`라면 연결이 완료되지 않은 상태입니다.

준비 완료를 확인한 후 [청첩장](https://www.maharex.com/love)을 새로고침하면 **“함께할 봄날을 알려주세요”** 영역이 나타납니다. Vercel에서 다시 배포할 필요는 없습니다.

## 4. 두 사람만 참석 명단 확인하기

1. [참석 명단 관리 화면](https://wedding-api.maharex.com/api/rsvp-admin)을 엽니다.
2. PC에 보관한 **참석명단-접속키.txt**를 열어 키를 복사합니다.
3. **참석 명단 열람 키** 칸에 붙여넣고 **명단 확인하기**를 누릅니다.

이름, 신랑·신부측, 참석 여부, 인원, 식사 여부와 전체 인원 합계를 확인할 수 있습니다. **전체 명단 CSV 저장**을 누르면 엑셀에서 열 수 있는 파일을 받습니다. 명단은 하객에게 공개되지 않습니다.

관리 화면을 새로고침하거나 닫았다가 열면 키를 다시 입력해야 합니다. 새 응답은 관리 화면의 **새로고침**으로 확인해 주세요.

카카오톡 자동 알림은 아직 연결되지 않았습니다. 카카오톡으로 알림을 받으려면 별도 발송 서비스 연결이 필요하며, 현재는 위 관리 화면에서 확인합니다.
